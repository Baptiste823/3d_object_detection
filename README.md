# 3d_object_detection
Repository for the module#1 of ThinkAutonomous' 3D Computer Vision program: https://www.thinkautonomous.ai/courses

This workshop is about building a complete 3D vision pipeline in 5 steps, starting from loading stereo images to detecting objects in 3D space.
We generate disparity maps using Stereo BM/SGBM algorithms, compute depth maps, and fuse this depth data with 2D object detection bounding boxes.
Finally we build a 3D reconstruction of the scene
